# naive base project

### by yeruham mendelson

**This project implements a Naive Bayes model for analyzing tabular data stored in CSV files.**

- Place your CSV files in the data directory.

- When running the model, you can specify which column in the table you want to classify.

- The model uses 70% of the data for training and 30% for testing,
- providing an accuracy score based on the test set.

- After training, you can use the classified API to input new data
- (with values matching the original datasets features),
- and the model will predict the value of the classified column.
